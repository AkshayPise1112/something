# T→G Frontend Application

The modern, responsive React + TypeScript + Vite + Tailwind CSS frontend for **T→G (Trend to Growth)**.

## Visual Design Identity
- **Glassmorphism**: Translucent panels with subtle blur, light border, and soft elevation
- **Color Palette**: Growth Green (`#22C55E`), Professional Blue (`#3B82F6`), Ambient Soft Background (`#F7FCF9`)
- **Signature Feature**: Trend Finder with vertical card reels/shorts CSS scroll snap discovery

## Features
- Landing Page with interactive value loop
- Executive Dashboard with 5 KPI glass cards & Recharts graphs
- Trend Finder with keyboard & wheel swipe
- Explore Trends with search & category filters
- Trend Details with multi-timeframe analytics, audience demographics, and geographic signals
- Opportunities & Action Plans
- Human Expert Validation quality gate
- Experiment Center with live daily metrics tracking
- Smart Alerts with notifications
- Ask T→G conversational intelligence advisor
- Business Profile onboarding & intelligence provider switcher
- Mission Control Admin Dashboard

## Local Development
```bash
npm install
npm run dev
```
Runs at `http://localhost:5173`.
